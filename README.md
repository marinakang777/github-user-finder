# github-user-finder
GitHub User Finder — десктопное приложение для поиска пользователей GitHub и сохранения избранных профилей.Приложение позволяет:  искать пользователей GitHub по логину;  просматривать основную информацию о профиле;  добавлять пользователей в список избранного;  сохранять избранное между сессиями работы.
