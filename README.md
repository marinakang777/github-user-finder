# github-user-finder
GitHub User Finder — десктопное приложение для поиска пользователей GitHub и сохранения избранных профилей.Приложение позволяет:  искать пользователей GitHub по логину;  просматривать основную информацию о профиле;  добавлять пользователей в список избранного;  сохранять избранное между сессиями работы.

## Описание

Приложение «GitHub User Finder» позволяет искать пользователей GitHub по имени, просматривать результаты и добавлять избранных пользователей в локальное хранилище. Данные избранных пользователей сохраняются в JSON файл.

## Технологии

* Python 3
* Tkinter (GUI)
* requests (работа с API)
* JSON (хранение данных)

## Как использовать  GitHub

Приложение использует публичный GitHub  (https://github.com). 
Для запуска прложения склонируйте репозиторий: 
 git clone https://github.com
cd github-user-finder
git init

запустите программу github_user_finder

Примеры использования приложения github_user_finder:

1.Базовый поиск пользователя(информация о пользователе по логину)
2.Поиск несуществующего пользователя(ошибка при вводе неверного логина)
3.Добавление пользователя в избранное
4.Удаление из избранного
5.Сохранение и загрузка избранного
6.Обработка сетевых ошибок(временное отсутствие интернет соединения.)
